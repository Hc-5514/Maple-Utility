# 넥슨 보스 미리보기

`frontend`에서 `pnpm dev:mock --host 127.0.0.1 --port 5176` 실행 후
`http://127.0.0.1:5176/` 접속. 모의 로그인 자동 적용.

- 원본: Nexon Open API `character/list`, `character/basic`, `scheduler/character-state`
- 수집일: 2026-10-07 KST
- 즐겨찾기: 꼬농, 말랑꼬농
- 실제 스냅샷: 캐릭터 기본 정보, 등록된 주간·월간 보스, 완료 상태, 일간·주간 콘텐츠
- 정적 카탈로그: V6 결정 가격과 V7 보스 드랍 목록 중 두 캐릭터의 등록 보스 조합
- 모의값: 캐릭터·보스별 고정된 1–3인 파티, 인원별 결정 금액과 이를 합산한 통계
- 미확인값: 실제 파티 인원, 결정석 판매 여부, 보스 아이템 획득 여부, 사냥 기록

API 키와 계정 ID·OCID는 Fixture와 클라이언트 번들에 포함되지 않음.
미리보기 저장은 브라우저 세션의 모의 API 상태만 변경하며 운영 DB와 무관.
새 넥슨 응답 반영 시 서버 측에서만 API 키를 사용하고 민감 식별자를 제거한 뒤 Fixture 갱신.
