# 넥슨 문의 초안 — 월간 보스 완료 플래그 및 날짜 경계 확인

상태: 초안 / 미발송 / API KEY·OCID·실제 계정 식별자 포함 없음

## 공식 근거

- [스케줄러 조회 안내](https://openapi.nexon.com/ko/support/notice/3482567/): 최대 14일 전 및 해당 일자의 마지막 정보 조회 안내
- [9/17 업데이트](https://openapi.nexon.com/ko/support/notice/3545814/): 월간 보스 미완료 오류 수정 및 업데이트 이후 처치부터 반영되는 조건

## 확인된 현상

- 사용자가 확인한 9월 처치 캐릭터 2개와 미처치 캐릭터 1개
- 10/13 02시 조회 성공 이후 저장된 9/30 플래그는 세 캐릭터 모두 false
- 당시 HTTP 본문 미보관, 저장값과 실제 원본 플래그 정확성 구분
- 10/14 10/1(D-13) 성공 → 10/15 같은 10/1(D-14) OPENAPI00004
- 10/15 10/2(D-13) 성공 및 date 생략 실시간 성공, 두 캐릭터 동일 재현
- 10/14 오늘 날짜 명시 실패와 date 생략 성공의 차이 확인

## 문의 항목

1. 과거 날짜의 실제 허용 범위 D-13~D-1 여부와 기준 시간대·D-14 거절의 의도 확인
2. 오늘 날짜 명시 거절 및 date 생략 허용의 의도 확인
3. 9/17 13시 이전 월간 보스 처치의 플래그가 이후 과거 조회에서도 미완료로 유지되는지 확인
4. 월말 조회의 complete_flag가 해당 월 누적 완료 상태인지 및 등록·난이도 변경 시 의미 확인
5. 원본 보관 기간 경과 후 당시 플래그 검증이 가능한 지원 경로 확인

9/30 고유 오류나 전체 월말 오류라는 단정 제외. 날짜 경계 실측과 9월 저장값 불일치의 별도 설명.

첨부 후보: 마스킹된 날짜·HTTP 상태 비교표. 실제 식별자가 필요한 문의 발송 단계는 별도 결정.
