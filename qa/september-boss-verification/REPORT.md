# 9월 월간 보스 처치 상태 불일치 조사

관련 이슈: #315 / 후속 기반: #313·#314 / 사용자 확인일: 2026-10-15

## 확인 사실

| 캐릭터 | 난이도 | 사용자 확인 | 10/14 조사 당시 9/30 DB | 판정 |
|---|---|---|---|---|
| 꼬농 | EXTREME | 처치 | false | 불일치 |
| 말랑꼬농 | HARD | 처치 | false | 불일치 |
| 도구꼬농 | HARD | 미처치 | false | 일치 |

사용자 확인은 실제 처치 여부의 근거. 당시 넥슨 원본 플래그 정확성의 확인 근거와 구분. 정확한 처치 날짜는 미확인.

- 꼬농의 9/1 기록은 true·synced_at=null, 10/10 생성으로 수동 등록 형태와 일치
- 꼬농의 9/30 자동 기록은 false·10/13 02시 동기화 기록, 이전 수동 행 자체의 삭제 없음
- 말랑꼬농·도구꼬농의 조사 당시 9월 기록은 9/30 false
- 비교군 꼬마렌의일기·꼬마별궁수·프로농구의 9/30 저장값은 true, 모든 월말 데이터가 false라는 가설의 반례
- [최소화된 증거](evidence.json): 저장 시각·값·사용자 확인과 원자료 SHA-256 기록

## 조회 규칙과 재현 결과

#317 머지 기준 main 코드의 분석 및 합성 데이터 회귀 검증.

- 과거 월말 FINALIZED가 있으면 월말 목록·플래그 사용, 수동 기록과 선택·숨김의 우선 적용
- FINALIZED가 없으면 기존 보스별 최신 날짜 조회, 수동 raw 기록의 별도 우선 적용은 FINALIZED 분기 안에서만 실행
- 따라서 꼬농처럼 9/1 수동 true·9/30 자동 false이며 확정 스냅샷이 없으면, 월 전체 조회는 9/30 false 선택
- 9/23 기준 요약은 미래 9/30 행을 제외해 9/1 true 선택, 9/30 기준 요약은 false 선택
- 10월 행은 9월 조회에 포함되지 않는 방식 적용
- 기존 boss_period_selections의 수동 선택·숨김은 별도 오버라이드 경로

위 결과는 저장 자료·리포지터리 실제 쿼리·main 소스 기준. 현재 운영의 인증된 HTTP 응답 및 배포 버전의 직접 재수집 결과는 아님.

미확정 월의 수동 raw 기록 우선순위는 현재 동작의 한계로 기록. 이번 작업의 조회 정책 변경·운영 데이터 수정 제외.

## 원본 확인 한계와 원인 구분

1. 10/13의 9/30 조회 성공·저장 이력은 존재하나 당시 HTTP 본문 미보관
2. 10/14의 9/30은 D-14로 HTTP 400, 10/15에는 전날 성공한 10/1이 D-14로 HTTP 400, D-13 및 date 생략 대조 요청은 정상
3. 날짜 경계 이동은 확인되었으나 넥슨 내부 기간 계산의 공식 답변은 미확보
4. 10/15의 9/30은 D-15로 과거 조회 범위 밖, 재호출을 통한 원본 복원 제외
5. DB 저장값 및 현재 10월 플래그만으로 당시 9월 원본 정확성 판단 불가

[넥슨 9/17 공식 안내](https://openapi.nexon.com/ko/support/notice/3545814/)에 보스 미완료 응답 오류 수정과 업데이트 이후 처치부터 반영되는 조건 존재. 적용 시각은 9/17 13시. 두 처치 캐릭터의 날짜가 없어 이번 불일치의 확정 원인으로 취급 불가.

## 조치와 제외 범위

- DB를 새로 채울 예정이라는 사용자 결정에 따른 기존 9월 값 보정 제외
- 운영 DB 초기화·기존 원본 false의 true 변경·9월 FINALIZED 스냅샷 생성 제외
- 공개 API·DTO·서비스·스키마 변경 없음
- 필요한 회귀 테스트 추가, 기존 #313·#314 테스트 재사용
- [TS](TS.md) 및 [넥슨 문의 초안](support-inquiry.md) 작성, 문의 발송 제외
- 원자료는 저장소 밖 권한 제한 디렉터리에 별도 보존, 초기화 작업과 별개

## 이후 DB 재수집 시 확인 사항

별도 DB 초기화 작업의 확인 목록이며 실행 절차나 초기화 승인으로 취급 제외.

- 초기화 전에 조사 증거·필요 백업 확보 및 별도 복구 절차 검토
- 현재 등록 월간 보스의 실시간 API·저장값·화면 표시 대조
- 지난주 확정과 월말 확정의 대상·진행률·실패 상태 확인
- 9월은 새 데이터 수집으로 자동 복원되지 않는 기간, 운영 보정 제외 결정을 유지
- 정확한 처치 날짜 또는 넥슨 답변 확보 시 조사 결론 재검토
